# ⚛️ React Todo App

A modern and responsive Todo App built using React.js.

## 🚀 Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- LocalStorage support
- Enter key task add support
- Dynamic task counter
- Modern glassmorphism UI
- Responsive centered layout

## 🛠️ Technologies Used

- React.js
- JavaScript
- CSS3
- Vite

## 📦 Project Structure

- App.jsx
- App.css
- main.jsx
- index.css

## 🎯 React Concepts Practiced

- useState
- useEffect
- Event Handling
- Conditional Styling
- Array Mapping
- Filter Method
- LocalStorage
- Dynamic Rendering
